# Triage Labels

Matt 工程技能使用五个标准 triage 角色。本项目直接采用相同的 label 字符串。

| Matt Pocock skill role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已经明确，可以交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 使用 triage role 名称时，直接使用右侧同名 GitHub label。GitHub remote 配置完成后，创建这些 labels 并保持名称不变。
